# java-lotto-precourse 기능 목록
## 1. 입력
- 구입 금액을 입력받는다.
  - 정수여야하며 1000원 단위로 나누어떨어져야 한다.
- 당첨 번호 6개를 입력 받는다.
    - 쉼표로 구분되며 1~45 범위, 중복이 없어야 한다.
- 보너스 번호 1개를 입력받는다.
    - 1~45 범위이며 당첨 번호와 중복되면 안 된다.
## 2. 발행
- 구입 금액을 바탕으로 로또를 발행한다. (1000원당 1장)
- 한 장은 1~45 범위의 중복 없는 6개의 숫자로 구성된다.
- 발행된 각 로또의 숫자는 오름차순으로 정렬해 보여준다.

## 3. 결과 계산
- 발행된 각 로또와 당첨 번호를 비교해 일치 개수와 보너스 일치 여부를 판단한다.
- 일치 개수에 따라 1등~5등을 집계한다.
  - 1등: 6개 일치 / 2,000,000,000원
  - 2등: 5개 일치 && 보너스 볼 일치 / 30,000,000원
  - 3등: 5개 일치 / 1,500,000원
  - 4등: 4개 일치 / 50,000원
  - 5등: 3개 일치 / 5,000원
## 4. 출력
- 발행한 로또 개수와 각 로또 번호(오름차순)를 출력한다.
- 등수별 당첨 내역(개수)을 출력한다.
- 총 수익률을 지정된 형식으로 출력한다.

## 5. 예외 처리
- 잘못된 입력이 들어오면 IllegalArgumentException을 발생시킨다.
- 에러 메시지는 [ERROR]로 시작한다.
- 예외가 발생한 경우 그 입력부터 다시 받는다.
